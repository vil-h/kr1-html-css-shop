# Нейробазар

«Интеллект продаётся, ошибки бесплатно».

Учебный интернет-магазин нейросетей для КР №1 по дисциплине «Фронтенд и бэкенд разработка».

**Автор:** Мукаев Вильдан Рустамович  
**Группа:** ЭФБО-06-25

В каталоге представлены ChatGPT, Claude, Gemini, Midjourney, Perplexity и GitHub Copilot. Все цены вымышленные и указаны в тенге. Это учебный сайт: подписки не продаются, платежи и данные покупателей не принимаются.

## Страницы

- `index.html` — главная страница.
- `catalog.html` — каталог шести нейросетей.
- `product.html` — описание товаров и таблицы характеристик.
- `order.html` — учебная форма заявки.
- `contacts.html` — контакты и ответы на вопросы.

## Технологии

HTML5, CSS3, Flexbox, Grid, БЭМ и немного JavaScript для модальных окон. Стили находятся в `css/style.css`, скрипт — в `js/main.js`, изображения — в `images/`. Bootstrap и другие CSS-фреймворки не используются.

## Как открыть

Откройте `index.html` в браузере. Устанавливать зависимости не нужно.

После включения GitHub Pages для ветки `main` сайт будет доступен по адресу: https://vil-h.github.io/kr1-html-css-shop/

**Репозиторий:** https://github.com/vil-h/kr1-html-css-shop
